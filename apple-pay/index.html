Send Apple Pay purchases to your signed-in Necessary account using a Wallet automation in Shortcuts.

Download for iOS 27 · Updated October 3, 2026

Download shortcut

Install Necessary and sign in first. The shortcut is free and does not contain a connection key or saved payment cards.

Set up on iOS 27

  1. Download the shortcut. Tap Download shortcut above. If Safari asks, confirm the download, then open the downloaded file from Safari’s downloads or Files.
  2. Open it in Shortcuts. Tap Set Up Shortcut, then Skip Setup to add it with the automation turned off.
  3. Edit the automation. Open Necessary Apple Pay and tap Editor if the description view appears. In the “When Cards is tapped” row, choose your cards or Any Card, then tap Done.
  4. Enable it. Expand the Wallet trigger with its arrow, then turn on Automation. Tap Back when you’re done; Shortcuts saves the changes.
  5. Check a purchase. Make a small Apple Pay purchase and open Necessary to confirm the transaction appears for review.

What gets sent?

The shortcut passes the transaction’s name and amount, the card name, and the current date. Wallet may leave out details for some purchases or preauthorizations. Necessary skips events without a merchant; purchases without an amount wait for you to enter it in the app.

Using iOS 26 or earlier?

Create the automation manually in Shortcuts instead of importing its automation from the file.

  1. In Shortcuts, open Automation, tap +, and choose the Wallet transaction trigger.
  2. Select your cards and choose Run Immediately.
  3. Add Necessary’s Add Apple Pay Transaction action.
  4. Fill Merchant and Amount using the Wallet transaction’s properties. Use Current Date for Date and the card name for Account Name.
  5. Save it and check a small purchase in Necessary.

Already have the shortcut?

Downloading a new copy does not update an existing automation automatically. Update or replace your existing setup, and leave only one automation enabled to avoid duplicate imports.
